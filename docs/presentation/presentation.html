OPENING / SCORINGAI QUIZ GENERATOR

The LLM never grades the learner

The assessment formula is implemented as isolated, deterministic TypeScript policy.

Per question

Single: correct = 4; wrong = 0.
Multiple: 1 point per correctly selected option, capped at 4.
Wrong selections add 0; no deduction.
Policy is provisional because the task is ambiguous.

Final score

weight(i) = 1.1 ** i, starting at i = 0.
score = Σ(scoreᵢ × weightᵢ) / Σ(weightᵢ).
Store on the 0–4 scale.
Round score and percentage only for display.
Consequence: an all-correct multi-select sitting may score below 4; selecting every option is not penalized.

DEEP DIVE / 1 · INPUTAI QUIZ GENERATOR

Validate before spending model tokens

The HTTP adapter parses public contracts, applies admission limits and delegates to the use case.

request = Zod.parse(body)
assert 1 <= topic.length <= 200
assert sourceUrl is an HTTPS URL
count = request.count ?? 5   // 5..8
strategy = request.strategy ?? 'balanced'

permit = limiter.tryAcquire(clientIP)
if rate limit: return 429
if concurrency limit: return 503
try: return createQuiz.execute(request)
finally: limiter.release()

Why here?

Malformed input never reaches fetch or AI.
5 attempted creates / client / 60 seconds.
2 admitted creates in flight / process.
Stable errors give the UI a recovery path.
The limits are in-memory and process-local; shared admission control is future work for multiple replicas.

DEEP DIVE / 2 · INGESTAI QUIZ GENERATOR

Resolve the URL into bounded bytes

The server fetches source content; the browser does not proxy arbitrary URLs or parse returned HTML.

original = inputURL
current = normalizeGitHubBlob(parseHTTPS(original))
for each hop, at most 3 redirects:
  assert HTTPS, no credentials, port 443
  addresses = DNS.lookupAll(current.host)
  assert every address is public
  response = HTTPS.getPinned(addresses[0])
  if redirect: resolve Location; repeat checks
  assert 2xx, allowed media type, <= 512 KiB
  snapshot = normalizeAndHash(response.body)
  return original, current, snapshot, fetchedAt

Operational bounds

10-second request timeout per fetch hop.
3 redirects maximum.
Stream-size enforcement, plus final size check.
Allow Markdown/plain text; reject HTML responses.
GitHub blob → raw preserves the source identity while retrieving Markdown rather than a repository web page.

Validate DNS and pin the connection

Defense sequence

Reject private, loopback and link-local IPs.
Check IPv4, IPv6 and mapped IPv4 forms.
Reject a DNS answer set containing any unsafe address.
Revalidate each redirect before connecting.

DEEP DIVE / 3 · PARSEAI QUIZ GENERATOR

Normalize Markdown without executing it

This is lightweight textual normalization, not an AST parser, crawler or Markdown renderer.

text = UTF8.decode(bytes, fatal=true)
reject if text contains NUL
normalized = removeHTMLComments(text).trim()
title = firstLineMatching('# heading')
assert normalized.length >= 200
hash = SHA256(UTF8(normalized))
return { contentSnapshot: normalized,
         contentHash: hash, title,
         originalUrl, resolvedUrl, fetchedAt }

What survives

Headings, links, code blocks and punctuation.
No script or embedded code execution.
No link crawling or dependency downloads.
The hash fingerprints normalized text, not raw bytes.
The full normalized snapshot is durable evidence; changing source content yields a different fingerprint.

Ground an excerpt back to source text

Tolerant matching handles whitespace and Markdown links while retaining the actual source span.

for question in questions:
  candidates = [excerpt, stripWrappingQuotes(excerpt)]
  found = exactSubstring(snapshot, candidates)
       ?? matchCollapsedWhitespace(snapshot, candidates)
       ?? matchUnwrappedLinksWithOffsetMap(snapshot)

// Example: 'Fastify' can map back to

DEEP DIVE / 10 · GRADEAI QUIZ GENERATOR

Make the score policy explicit

Small pure functions expose the ambiguous part of the task and keep it easy to change after clarification.

scoreSingle(question, selected):
  assert selected.length == 1 and owned(selected)
  return correct(selected[0]) ? 4 : 0

scoreMultiple(question, selected):
  assert selected.length >= 1 and uniqueOwned(selected)
  count = selected.filter(isCorrect).length
  return clamp(count, 0, 4)

rawScores = quiz.questionsInOrder.map(scoreQuestion)
final = weightedAverage(rawScores, ratio=1.1)

Example

Correct set: A + C.
Select A → 1 point.
Select A + C → 2 points.
Select A + B + C + D → 2 points.
No normalization or wrong-choice penalty.
This provisional policy matches the documented interpretation, but permits select-all gaming on multiple questions.

DEEP DIVE / WEIGHTINGAI QUIZ GENERATOR

A hand-checkable weighted average

Illustrative five-question example: later positions have 10% more weight than the preceding position.

position i:    0       1       2       3       4
weight:        1.0     1.1     1.21    1.331   1.4641
raw score:     0       4       4       4       4

weighted sum = 4 × (1.1 + 1.21 + 1.331 + 1.4641)
             = 20.4204
weight sum   = 6.1051
score        = 20.4204 / 6.1051
             ≈ 3.34481008 / 4
display      = 3.34 / 4; 83.62%

Invariants

Weight starts at 1.0, not 1.1.
Divide by the sum of weights.
Keep quiz order independent of request order.
Do not round intermediate results.
